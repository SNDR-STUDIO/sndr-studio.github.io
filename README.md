# SNDR Studio Portfolio

A modern portfolio website showcasing motion design and web development work by Alexandr (SNDR Studio).

## 🎯 Overview

This portfolio website demonstrates expertise in:
- Motion Design & Animation
- Web Development & UI/UX Design  
- Brand Identity & Social Media Content
- Video Production

Built with modern web technologies and featuring smooth animations, interactive elements, and a clean, professional design.

## 🛠️ Technology Stack

### Frontend
- **HTML5** - Semantic markup structure
- **CSS3** - Custom styling with animations and responsive design
- **JavaScript (Vanilla)** - Interactive functionality
- **Bootstrap 5.3** - Responsive grid system and components
- **Bootstrap Icons** - Icon library
- **Swiper.js** - Touch-enabled slider for testimonials
- **AOS (Animate On Scroll)** - Scroll-triggered animations
- **GLightbox** - Lightbox gallery for portfolio items
- **PureCounter** - Animated counting statistics
- **Typed.js** - Animated typing effect
- **Lenis** - Smooth scrolling
- **Three.js** - WebGL background effects

### Key Features
- ✅ Fully responsive design (mobile-first approach)
- ✅ Smooth scroll navigation
- ✅ Animated sections on scroll
- ✅ Video background elements
- ✅ Interactive portfolio filtering
- ✅ Testimonial carousel
- ✅ Lazy-loaded media for performance
- ✅ Service Worker support (PWA-ready)
- ✅ Cross-browser compatibility

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/sndr-studio/sndr-studio.github.io.git
   ```

2. **Open the project**
   - Simply open `index.html` in any modern web browser
   - No build process or dependencies required
   - All assets are self-contained in the `assets/` directory

3. **Development**
   - Edit `index.html` to modify content
   - Customize styles in `assets/css/minify_main.css`
   - Update functionality in `assets/js/main.js`
   - Replace media files in `assets/img/` and `assets/video/` as needed
